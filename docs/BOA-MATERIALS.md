## 最值得补的循环视频

| 优先级 | 演示 | 推荐镜头 |
| --- | --- | --- |
| 1 | 批量纠正分类 | 进入某类交易 → 选中两笔 → 选择新分类 → 确认 → 展示更新后的列表与总额。约 10–15 秒。 |
| 2 | 完整预算保存 | 调配分类额度 → 展示两边新上限与总额 → Save Budget → 选择仅本月/持续生效 → 展示结果。现有第三段录屏未展示最后的保存范围选择。约 12–18 秒。 |
