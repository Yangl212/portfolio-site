## 已完成

- 首屏前置角色、周期、个人贡献和交付物，增加原型直达入口。
- 主线整理为看懂消费、追溯明细、调整预算；三段循环视频分别配设计理由和取舍。

- 测试结果优先呈现 3/6 → 5/6 等实际人数；说明助手比较使用了不同恢复路径，不能单独归因于 AI。

## 研究数据：沿用原文，仍待核对记录

现有页面的 32 份问卷、2 次访谈、两轮六人测试和相关数值没有新增或重新生成。本次尚未取得原始记录，不能将排版整理视为独立验证。

建议补齐：

1. 问卷题目、每题有效回答人数和选项计数。现有百分比需与实际分母对应。
2. 两次访谈的关键观察与对应设计决定。现有照片作为场景图，不能替代访谈摘录。
3. 两轮测试是否同一批参与者、任务是否一致、成功与需要帮助的判定标准，以及用时/误点的原始记录。
4. 助手任务的第一轮是导航恢复、第二轮使用助手，保留这一差异，避免写成只改变一个因素的对照实验。

## 最值得补的循环视频

| 优先级 | 演示 | 推荐镜头 |
| --- | --- | --- |
| 1 | 批量纠正分类 | 进入某类交易 → 选中两笔 → 选择新分类 → 确认 → 展示更新后的列表与总额。约 10–15 秒。 |
| 2 | 完整预算保存 | 调配分类额度 → 展示两边新上限与总额 → Save Budget → 选择仅本月/持续生效 → 展示结果。现有第三段录屏未展示最后的保存范围选择。约 12–18 秒。 |
| 3（有真实记录后） | 迭代前后 | 同一个任务、相同画面尺寸，对照旧版卡点与修改后的交互。附真实发现及改动原因。 |

MP4 H.264、30fps、静音，手机本体宽至少 720px。重要状态停留约 2 秒，结尾回到初始状态以便循环。优先纯界面或紧裁手机录屏，无需大面积背景，也无需加入播放条。

现有素材中的“Hover”提示不适合解释手机操作。下一次导出时可同步改为与点击、轻触操作一致的提示。
